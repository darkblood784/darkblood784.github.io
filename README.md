## Local Development

Because this is a simple static site, no build step is required.

1. Clone the repository.
2. Open `index.html` directly in a browser, or serve the folder with any static server.
3. Update content in `index.html` and visual styles in `styles.css`.

Example using a local static server:

```bash
# Python
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

The site is intended for GitHub Pages deployment. Any change pushed to the published branch can be served as a static website.
